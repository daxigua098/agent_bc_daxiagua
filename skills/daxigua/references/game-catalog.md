# 玩法大类与结算依据

## 通用原则

1. **局结果是唯一真源。** 注单的输赢由厂商（或自研引擎）出具的局结果决定。本地系统只做镜像、校验与对账，绝不自己重算出一个不同的结果。
2. **先定责任边界，再谈玩法。** 明确哪些玩法是自研、哪些接第三方；第三方玩法的规则、结算、限额一律以厂商规则文档为准。
3. **每个玩法要能回答四个问题：** 怎么下注、什么时候封盘、按什么判定输赢、异常局怎么处理。
4. **随机类玩法的公平性要有可验证依据。** 电子游艺、彩票类要说明 RNG 或开奖来源、RTP 口径、以及玩家可查证的记录。

下面每类给出实际会踩的坑，具体规则数字仍需以厂商文档或运营确认为准。

## 彩票类

高频开奖玩法（时时彩、快 3、11 选 5 等）与开奖类玩法（六合彩等）。

- 常见下注：定位胆、大小单双、龙虎、和值、跨度、组选。
- 结算依据：官方开奖号码或指定权威数据源；必须有开奖数据接入与校验流程。
- 坑：开奖延迟时是否允许下注、开奖号码来源争议、跨天归属日期、停售与开奖之间时间窗口。这些要在规则文档里写死。

## 棋牌类

斗地主、麻将、牛牛、炸金花、德州扑克等。

- 结算依据：牌局结果 + 玩家桌内输赢；平台抽水通常按每局底池或固定水钱。
- 关键设计：房间与上桌门槛、超时托管与自动弃牌、断线重连后的状态恢复、牌局记录可回放。
- 坑：牌局中途解散如何结算、玩家掉线超时判定、抽水算毛利还是先扣后算、赛事/竞技模式的独立结算规则。

## 电子游艺（老虎机、Slots）

- 结算依据：厂商单局结果（spin result），含 bet、win、balance。
- 关键数字：RTP（返奖率）、波动率、最大赢取倍数、免费旋转与彩金触发规则。
- 坑：免费游戏与彩金可能跨局甚至跨会话，结算与对账要能覆盖；不同机台 RTP 不同，报表不能混算。

## 捕鱼 / 街机类

- 结算依据：每发子弹的开火成本与命中收益；房间分不同炮值。
- 坑：并发开火时的扣款顺序、命中判定与掉线补偿、房间爆机/限额控制、以及「打不死」类投诉如何用日志自证。

## 真人视讯

百家乐、龙虎、骰宝、轮盘、21 点等，通常是接第三方厂商的直播桌台。

- 结算依据：厂商局结果（game result）+ 桌面限额。
- 坑：下半局（改注）是否允许、荷官操作失误或牌局取消时的作废规则、直播卡顿时的取消窗口、桌台维护与切换、多桌并发时余额扣款的实时性与幂等。

## 体育竞猜

足球、篮球、网球、棒球等，含赛前与滚球。

- 结算依据：按官方赛果与所选盘口结算；核心不是赛果本身，而是**盘口定义**（让球、大小、独赢、波胆、半全场等）。
- 必须写清的异常情形：比赛中断或腰斩、改期与换场、球队/球员退赛、赛果被官方改判、加时与点球是否计入、以及「结算依据时间点」。
- 滚球额外要求：赔率推送时效、接受赔率变动策略、封盘瞬间的注单裁决（以接受时间还是服务器时间为准）。
- 坑：把不同盘口（如让球 0.5 与让球 1）当同一规则结算；同一场比赛不同数据源的赛果不一致。

## 电竞竞猜

- 结算依据：赛事方或数据商结果；注意地图/局数与整场（BO3/BO5）的区别，以及「胜者改判」的追溯处理。
- 坑：比赛延期、弃权、重赛、相同赛事不同规则版本。

## 虚拟体育 / 随机赛事

- 结算依据：引擎生成的赛事结果，需要能提供可核查的记录与随机性说明。
- 坑：与真人体育共用报表或合计算法，导致指标口径混乱。
