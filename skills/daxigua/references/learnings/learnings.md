# 大西瓜学习日志

这是跨项目复用的经验库。每次项目收尾追加一条，只写真实发生过、能被验证的结论。

## 记录规则

- 只记录三类内容：项目验证过的结论、厂商明确给出的口径、踩过的坑与判定依据。
- 不记录猜测、未验证的传闻、客户隐私与真实账号数据。
- 结论稳定且跨项目通用时，回写进对应的 `references/*.md` 正式章节，并在这里标「已回写」。
- 与旧条目冲突时不要覆盖，追加新条目并注明日期与来源，标「待复核」。
- 一条记录只讲一件事，便于检索。

## 条目模板

```md
### YYYY-MM-DD <一句话结论>

- 项目/场景：
- 玩法或模块：
- 结论：
- 依据/来源：厂商文档 / 运营确认 / 实测数据（写明可追溯的出处）
- 适用范围：哪些项目、玩法、币种或辖区适用
- 影响的知识文件：references/xxx.md（是否已回写）
- 待复核：
```

### 2026-09-24 客户端授权默认只验用户名 + 有效期，机器码和 IP 可选

- 项目/场景：登录模版 / 可复用登录平台 V2
- 玩法或模块：客户端授权
- 结论：默认策略是 verify_username=true、check_expiry=true，verify_machine_code / verify_ip 默认关闭。一刀切绑机器码会让换机、换网络全部变成人工工单。校验顺序固定为 账户状态 → 用户名 → 密码 → 有效期 → 机器码 → IP → 设备名额。
- 依据/来源：服务端 LicenseService 实现 + 总体设计说明书
- 适用范围：带授权/有效期的客户端分发

### 2026-09-24 授权失败要返回可区分状态码，且创建时间与首次激活时间必须分开存

- 项目/场景：登录模版
- 玩法或模块：授权状态与运营字段
- 结论：AUTHORIZED / PENDING_APPROVAL / DENIED / EXPIRED / NOT_STARTED / MACHINE_MISMATCH / IP_MISMATCH / USER_NOT_FOUND / USER_DISABLED / INVALID_CREDENTIALS / PASSWORD_NOT_SET 要各自可区分，客户端才能给出可操作提示。added_at（管理员创建）与 first_activated_at（首次授权成功）必须分开，合并后无法回答"这个用户到底用没用过"。
- 依据/来源：服务端 LicenseService + 用户管理实现
- 适用范围：所有授权/会员有效期系统

### 2026-09-24 采集用「实时读内存 + 历史读库 + 唯一约束幂等」

### 2026-09-24 派生字段（期号、号码）在服务端入库时算好，客户端不重算

- 项目/场景：登录模版
- 玩法或模块：期号与开奖号码派生
- 结论：期号 = YYYYMMDD + (Hour×60 + Minute + 1) 补 4 位；号码 = 各位数字求和取个位 + 原始数值后四位（五位数）。服务端入库即算好落库，客户端只读。两端各算一次迟早会因为时区和边界条件对不上。
- 依据/来源：服务端 README「期号与开奖号码计算规则」+ issue_calculator 实现
- 适用范围：按时间派生期号的玩法
- 影响的知识文件：references/cases/reusable-login-platform.md（已回写）
- 待复核：—

### 2026-09-24 高频彩抽水实际扣减 = 界面显示比例 + 0.1%

- 项目/场景：登录模版（任四组选 4 / 组选 6 赔率核算）
- 玩法或模块：赔率与派彩
- 结论：最终得到值 = 基础值 × [1 − (显示抽水比例 + 0.1%)]。显示 5.0% 时乘数 0.949：组选 4（基础值 5000）得 4745、单注派彩 2.3725 元、每期投入 0.45 元、中 1 注净盈 +1.9225 元；组选 6（基础值 3333.33）得 3163.333、单注派彩 1.581667 元、每期投入 0.225 元、中 1 注净盈 +1.356667 元。穷举十万种号码实测中奖率：组选 4 为 8.55%、组选 6 为 11.70%，每期期望为投入 ×(−5.1%)，与"5% + 0.1% 手续费"吻合。
- 依据/来源：项目《赔率算法》文档 + 服务端 two_price 实现交叉核对，用期望值反推验证
- 适用范围：该玩法与抽水口径；换平台必须重新核对参数
- 影响的知识文件：references/lottery-payout-calc.md（已回写）
- 待复核：**《赔率算法》文档里组选 6 的对照表用的是 3333.33×0.950=3166.664，与实测值 3163.333 冲突**；实测与逆推结论（×0.949）优先，原表待作者确认。换平台或平台改版后需重新用期望值法验证。
